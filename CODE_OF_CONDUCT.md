# Code of Conduct

## Our standard

Scale Content HQ is a collaborative project. We are committed to a welcoming environment for contributors of every background and experience level.

Be respectful, constructive, patient, and specific. Critique ideas and code without attacking people. Do not use harassment, discrimination, threats, sexualized language, or deliberate disruption.

## Scope

This code of conduct applies in repository issues, pull requests, discussions, and other spaces representing the project.

## Enforcement

Report unacceptable behavior privately to the project maintainer through the contact method listed on the maintainer's GitHub profile. Reports will be reviewed promptly and handled with appropriate confidentiality.

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior conflicts with these standards.
